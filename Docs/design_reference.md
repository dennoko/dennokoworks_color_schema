# Design Reference: dennoko.dev Modern UI

## デザインコンセプト：暗部のレイヤーとフローティング（Floating & Elevation）

全体のイメージは「シンプル＋暗めのモノトーン」でありながら、要素が暗闇の中に浮かび上がっているような**フローティングデザイン**が採用されています。これにより、モダンでメリハリのある印象を作っています。

### 1. 空間と背景 (Space & Background)
*   **ソリッドな闇:** 背景はソリッドな暗色（`surface-0` 相当）。グラデーションではなくフラットなベタ塗りで、奥行きの「最下層（ゼロ地点）」を表現。
*   **余白 (Whitespace):** 各セクション間に十分なマージンを取り、要素同士の密集を防ぐことで、洗練されたミニマルな空間を維持しています。

### 2. コンポーネント (Components)
*   **カードスタイル (Cards):** リストアイテムやリンクは、背景よりも一段階明るいグレー（`surface-1` 相当）の角丸矩形（カード）として表現されています。
*   **角丸 (Border-radius):** カードの角は滑らかに丸められており（8px ~ 12px程度）、無機質なモノトーンの中に柔らかさと近未来的な印象を与えています。
*   **ドロップシャドウ (Drop Shadow):** カードの下部や周囲にごく僅かな影（ほぼ黒に近いぼかし）を落とすことで、カードが背景から僅かに「浮いている（Floating）」ように見えます。これが「明度の差」と相まってElevationを作り出しています。

### 3. タイポグラフィと階層 (Typography & Hierarchy)
*   **セクションヘッダー:** 「PORTAL」「SOCIAL」「SHOP」などのカテゴリー名は、非常に小さく、太めで、かつ暗いグレー（`typography.tertiary`相当）で全設定されており、控えめに構造を示しています。
*   **主要テキスト (Titles):** 各カードのメインタイトルやページトップのドメイン名は、最も明るい白（`typography.primary`）で表示され、強いコントラストで視線を誘導します。
*   **補助テキスト (Subtitles):** 「VRChat account」「Tools & Shaders」などの補足説明は、一段暗いグレー（`typography.secondary`）で記述され、情報に優先度をつけています。

### 4. インタラクション (Interactions)
*   **アイコンと矢印:** カードの左にアイコン（少し浮き出たような四角形の背景付き）、右に小さな「`>`（シェブロン）」アイコンを配置することで、そのカードが**クリッカブル（クリック可能）**な要素であることを直感的に伝えています。
*   **ホバー表現の示唆:** おそらくマウスホバー時に、カードの明度が上がる（`surface-2` または `hoverOverlay` の適用）、もしくは影が強くなることで、UIが「触れる」ものであることを示します。

## まとめ：「メリハリ」を生む方程式

このデザインにおけるメリハリは、派手な色ではなく**「極端なコントラストの管理」**から生まれています。

1.  **ベースのコントラストは低く:** 背景(`surface-0`)とカード(`surface-1`)の明度差はあえて少なくし、シームレスな空間を作る。
2.  **文字のコントラストは高く:** 最も伝えたい文字情報だけを純白でコントラスト比を最大にする。
3.  **Elevationによる分離:** ごくわずかなシャドウと角丸で層（レイヤー）を表現し、フラットになりすぎない物理的な浮遊感を持たせる。

これをコードに落とし込む際は、Box-shadowやCSS変数（カスタムプロパティ）による微細な明度コントロールが鍵となります。
