# 画面パターン（L3）

ツールの画面全体の組み方。パターンを 1 つ選び、`assets/Patterns/` の雛形をコピーして始める。
カード（ブロック）の中身は [cards.md](cards.md)、上下の標準ヘッダー・標準フッターは `references/window-guide.md`。

## 0. パターンの選び方

| パターン | 一言で | 判定の質問 | 雛形 | 該当ツール |
| --- | --- | --- | --- | --- |
| P1 変換 | 入力を選び、設定して、1 回出力する | 出力ボタンを押したら作業が終わるか | `P1_Convert.uxml` | NormalMapGenerator / FastCurvatureBaker / MatcapMaker / FolderTreeExporter / UniTex / BoxWeightTransfer / SocksTuku-ru |
| P2 手順 | 前の手順の結果を次の手順で使う | 順番を入れ替えると結果が変わるか | `P2_Steps.uxml` | HairChimera |
| P3 一覧編集 | たくさんの項目を見て、絞って、まとめて変える | 画面の主役が一覧か | `P3_List.uxml` | BatchRenamer / DenEmo / FolderCleaner / DennokoMAT |
| P4 シーン作業 | ウィンドウで始め、作業はシーンでする | 作業の大半がシーンのクリック・ドラッグか | `P4_SceneWork.uxml` | MaskMakerV4（一部：MeshSplitter / HairChimera のシーン選択） |
| P5 コンポーネント編集 | Inspector から編集モードに入り、結果をコンポーネントに保存する | 設定をシーン上のコンポーネントに持つか | `P5_Inspector.uxml` | DennokoMeshEditor / DennokoNormalEditor / DenLattice / CableGenerator |

迷ったときの優先順：シーン操作が主なら P4 / P5、一覧が主なら P3、手順があるなら P2、どれでもなければ P1。

## 共通の枠（標準ヘッダー・標準フッター）

P1〜P4（EditorWindow）は、上下を必ず次の形にする。中身（スクロール領域）だけがパターンごとに違う。

```
┌ Tool Name  v1.2.0 ↻            EN ? ⋮ ┐  標準ヘッダー：トップバー .dennoko-appbar（固定）
├───────────────────────────────────────┤
│  （パターンごとの中身）                 │  .dennoko-scroll（ここだけが縮む）
├───────────────────────────────────────┤
│ 出力先 …/Textures   [選択…]  ☐ 上書き │  出力ドック .dennoko-output（任意・2 行まで）
│ [情報欄]   [Secondary] [   Primary   ] │  フッター .dennoko-footer（--joined）
│ 保存: Body_normal.png                  │  ステータス .dennoko-status
└───────────────────────────────────────┘
```

- タブ（P2 の手順タブ）や作業中バナー（B7）は、トップバーの直下・スクロール領域の外に固定する。
- P5（Inspector）はコンポーネント名が Unity の見出しに出るので、トップバーは簡略版（`.dennoko-appbar--compact`：バージョン + ↻ と右側のアイコン）。フッターは置かない。

## P1 変換

```
┌ Tool Name  v1.2.0 ↻            EN ? ⋮ ┐  トップバー
├───────────────────────────────────────┤
│ ┌ 入力 ───────────────────────────┐  │  B1 対象カード
│ │ [Texture            ] [選択から] │  │
│ └─────────────────────────────────┘  │
│ ┌ 設定 ────────────────── ? Reset ┐  │  B2 設定カード（1〜3 枚）
│ │ ...                             │  │
│ │ ▸ 詳細  [512] [Linear]          │  │  閉じているときは値のチップで要約
│ └─────────────────────────────────┘  │
│ ┌ プレビュー ─────────────────────┐  │  B3 プレビューカード（任意）
│ └─────────────────────────────────┘  │
├───────────────────────────────────────┤
│ 出力先 …/Textures   [選択…]  ☐ 上書き │  B5 出力（ドック）
│ [              生成              ]    │  フッター
│ 保存: Body_normal.png                  │  ステータスバー
└───────────────────────────────────────┘
```

- 主ボタンは常に 1 つで、文言は動詞 1 語（「生成」「出力」「ベイク」）。入力が無い間は無効にし、ツールチップに理由を出す（「入力を選んでください」）。
- 入力が無くても設定カードは表示する（先に設定だけ決めたい人がいる）。プレビューは空の状態にする。
- 出力したらステータスバーに `保存: <ファイル名>` を出し、クリックで Project ビューの該当ファイルを Ping する。
- 入力が「1 つ」ではなく「一覧」になったら P3 として作る（バッチ処理）。

## P2 手順

```
┌ Tool Name  v1.0.0 ↻            EN ? ⋮ ┐
├───────────────────────────────────────┤
│ [1 切り分け ✓][2 パーツ][3 調整][4 出力] │  手順タブ（.dennoko-tabbar--steps）
├───────────────────────────────────────┤
│  その手順のカードだけ                   │  スクロール領域
├───────────────────────────────────────┤
│ [← 戻る]   [   次へ：パーツ   →   ]     │  フッター（戻る = Secondary）
│ Ready                                  │
└───────────────────────────────────────┘
```

- 主ボタンは「次へ：<次の手順名>」。最後の手順だけ「出力」になる。フッターは 1 つで、タブ切替に合わせて文言と処理を差し替える。
- 前の手順をやり直したら、それより後の手順の ✓ を外し、その手順を開いたときに警告行「前の手順が変わりました。もう一度確認してください」を出す。
- 手順は 3〜5 個まで。6 個以上になる場合は、手順をまとめるか P1 を複数のタブに分ける。

## P3 一覧編集

```
┌ Tool Name  v1.0.0 ↻            EN ? ⋮ ┐
├───────────────────────────────────────┤
│ ┌ 対象 ───────────────────────────┐  │  B1（フォルダ / ルートオブジェクト）
│ └─────────────────────────────────┘  │
│ [🔍 検索          ✕] [変更あり][警告] 12/480 │  B4 の検索行（固定）
│ ┌─────────────────────────────────┐  │
│ │ 行 / 行 / 行 …（ListView）       │  │  B4 リスト（ここだけが伸びる）
│ └─────────────────────────────────┘  │
│ ┌ 設定 ───────────────────────────┐  │  B2（一括操作の内容。折りたたみ可）
│ └─────────────────────────────────┘  │
├───────────────────────────────────────┤
│ 12 件を変更        [元に戻す] [ 一括適用 ] │  フッター（情報欄 + 主ボタン）
│ Ready                                  │
└───────────────────────────────────────┘
```

- **このパターンだけ、ページ全体の ScrollView を使わない。** ListView を ScrollView に入れると二重スクロールになり、仮想化も効かなくなるため、リストカードを伸びる領域にする。
- 実行すると戻せない操作（削除・上書き）は、実行前に B6 確認カードで差分を見せる。主ボタンにせず、Secondary + 確認ダイアログにする。
- 一覧の件数と選択数はフッターの情報欄（`.dennoko-footer__info`）にだけ出す（検索行の `12/480` は「表示中 / 全体」）。

## P4 シーン作業

状態は **Idle（未開始）と Working（作業中）の 2 つだけ**。出力は状態ではなくイベントとして扱い、出力後もそのまま作業を続けられる。

| 状態 | ウィンドウ | シーン | 主ボタン |
| --- | --- | --- | --- |
| Idle | B1 対象カードと主ボタンだけ。他のカードは描画しない | 何も出さない | 「作業開始」 |
| Working | B7 作業中バナー + 作業用カード（設定・プレビュー・出力） | [sceneview.md](sceneview.md) のシーン操作 UI | 「出力」（または「完了」） |

- 開始の入口はウィンドウの主ボタンと Hierarchy の右クリックメニュー。**シーンに開始ボタンは置かない**（このツールを使わない作業の邪魔になる）。
- 終了の入口はウィンドウのバナーの「終了」、シーンのツールパネルの ✕、Esc の 3 つ。どれも同じ終了処理を呼ぶ。
- 出力設定が 3 行以上なら、スクロール領域の最後に出力カード、出力ドックには要約チップだけを出す（[cards.md](cards.md) B5）。
- 自動終了・自動保存などの約束は [sceneview.md](sceneview.md) §4 セッション規約に従う。

## P5 コンポーネント編集（Inspector）

```
Idle                                         Working
┌ Inspector: Den Mesh Editor ─────────┐      ┌ Inspector: Den Mesh Editor ─────────┐
│ v1.0.0 ↻                    EN ? ⋮ │      │ v1.0.0 ↻                    EN ? ⋮ │
│ [       シーンで編集       ]        │      │ ● 編集中  Body   Esc で終了  [終了] │  B7
│ ┌ ブラシ ───────────────────────┐  │      │ ┌ ブラシ ───────────────────────┐  │
│ │ 半径 / 減衰 / ミラー           │  │      │ │ 半径 / 減衰 / ミラー（同期）    │  │
│ └───────────────────────────────┘  │      │ └───────────────────────────────┘  │
│ ┌ 編集の一覧 ────────────────────┐  │      │ ┌ 編集の一覧 ────────────────────┐  │
└─────────────────────────────────────┘      └─────────────────────────────────────┘
```

- 雛形 `P5_Inspector.uxml` は、`CreateInspectorGUI` で返す container（`dennoko-root dennoko-inspector-root`）にそのまま CloneTree する（`references/inspector-guide.md`）。
- Idle の主ボタンは「シーンで編集」。Working ではバナーに置き換わり、Inspector に主ボタンは無い（作業の本体はシーン）。
- シーンのツールパネルと Inspector の両方に同じ設定（半径など）が出る。値は 1 か所（コンポーネント）だけに持ち、どちらで変えてももう片方が即座に追従する。
- 選択を外す・別のオブジェクトを選ぶと Inspector が消えるので、セッションは Inspector の寿命に依存させない（[sceneview.md](sceneview.md) §4）。
